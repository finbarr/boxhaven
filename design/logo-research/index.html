Platform guidance & brand construction

Build the mark, then package the icon.

The core logo should work in one color. The desktop version adds its white tile and platform-specific treatment. Apple’s current layered workflow supplies masking and effects; the existing BoxHaven build uses a flattened PNG and .icns.

SurfaceDimensionsHow to use them
Apple layered icon1024 × 1024Unmasked layers for Icon Composer; system-rendered effects.
Current BoxHaven .icns16, 32, 128, 256, 512 pt @1× / @2×Verified against desktop/scripts/build.mjs; flattened artwork.
Windows Win3216, 24, 32, 48, 256px minimumAdditional theme and package variants depend on distribution.
GNOME128px master; 64 / 32px checksSeparate symbolic icon. Follow its own platform conventions.
BoxHaven core markSVG + one-color / reversedProposed deliverable after selection; test independently of the tile.
