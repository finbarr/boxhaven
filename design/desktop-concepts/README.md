# BoxHaven desktop design exploration

Six concepts generated with the built-in image_gen tool for visual review. These are proposals, not implemented UI. Icons and prices in the mockups are illustrative; retain the actual happy-box artwork and backend quotes in implementation.

Open `index.html` for an enlargable gallery including the current app. The exact prompt set and source paths are recorded in `prompts.json`.

- **A · Warm graphite:** Charcoal, amber, compact flat rows. [a-warm-graphite.png](a-warm-graphite.png)
- **B · Light paper:** Ivory surfaces and forest green accents. [b-light-paper.png](b-light-paper.png)
- **C · Cool slate:** Navy surfaces and ice blue accents. [c-cool-slate.png](c-cool-slate.png)
- **D · Native split:** Light Mac chrome around a dark terminal. [d-native-split.png](d-native-split.png)
- **E · Creation:** Visible size choices with specs and prices. [e-create-box.png](e-create-box.png)
- **F · Rename:** A small popover anchored to the box name. [f-rename-box.png](f-rename-box.png)
- **Current app:** Screenshot of the existing implementation using test data. [current-app.png](current-app.png)
